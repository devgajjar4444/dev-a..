## What Happens on Click

### For Each Game

**Matrix for Adi 🎮**
→ Click cell → Symbol appears → Turn switches → Check for winner

**Love Lock 🔐**
→ Click card → 3D flip → Emoji reveals → Match check → Sparkle if matched

**Cupid Shot 🏹**
→ Click heart → Heart vanishes → Score increases → Continue until miss

**Quick Fingers ⚡**
→ Click tile → Tile flashes → Color changes → Combo builds → Speed increases

**Do You Love Dev?** 💕
→ Click answer → Question fades → New Q slides → Continue → Results show %

**Guess the Date** 💌
→ Click card → Lifts up → Sparkles burst → 3D flip → Date reveals → Memory text fades in → Glitter animates → Progress bar updates → All done → Heart rain celebration!
