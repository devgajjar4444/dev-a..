1. MATRIX FOR ADI 🎮 - GAME FLOW
═══════════════════════════════════════════════════════════════════════════════════

START
  │
  ├─→ Empty 3x3 Grid Displays
  │
  ├─→ Adi's Turn
  │   ├─ Display: "Adi's Turn 💙"
  │   └─ User clicks cell → X appears
  │
  ├─→ Dev's Turn (AI)
  │   ├─ Display: "Dev's Turn 💖"
  │   └─ Computer calculates → O appears automatically
  │
  ├─→ Check Win Condition
  │   ├─ 3 in a row? → Someone wins!
  │   ├─ All cells filled? → Draw
  │   └─ Otherwise → Repeat from Adi's Turn
  │
  ├─→ Game Over
  │   ├─ Winner: Display "Adi Wins! 💙" or "Dev Wins! 💖"
  │   ├─ Animation: Victory sparkles, hearts rain
  │   └─ Sound: Victory chime
  │
  ├─→ Result Screen
  │   ├─ [Play Again] Button
  │   └─ [Back to Home] Button
  │
END

CLICK INTERACTION:
User clicks grid cell
    ↓
Is cell empty? YES → Place X
                NO → Ignore (already occupied)
    ↓
Check for win (Adi)
    ↓
If no win → Dev's turn (automatic placement)
    ↓
Check for win (Dev)
    ↓
If no win → Next round

2. LOVE LOCK 🔐 - GAME FLOW
═══════════════════════════════════════════════════════════════════════════════════

START
  │
  ├─→ Shuffle 5 emoji pairs → Create 10 cards
  │   └─ Emojis: 💖 😘 🐼 🍕 💍
  │
  ├─→ Display 10 face-down cards (5x2 grid)
  │   ├─ Display: "Adi vs Dev - Match pairs!"
  │   ├─ Adi Score: 0
  │   └─ Dev Score: 0
  │
  ├─→ Adi's Turn
  │   ├─ Display: "Adi's Turn 💙"
  │   ├─ User clicks first card → Card flips (3D)
  │   ├─ User clicks second card → Card flips (3D)
  │   │
  │   ├─→ Do cards match?
  │   │   YES → Cards stay revealed ✓
  │   │       → Adi Score +1
  │   │       → Sparkle animation
  │   │       → Check if all matched?
  │   │   NO → Cards flip back
  │   │      → Wait 1 second
  │   │      → Switch to Dev's turn
  │   │
  │   └─ Continue Adi's turn or Switch to Dev
  │
  ├─→ Dev's Turn
  │   └─ Same as Adi but for Dev
  │
  ├─→ Game Over (All 10 cards matched)
  │   ├─ Compare scores: Adi vs Dev
  │   ├─ Display: "Adi Wins!" or "Dev Wins!" or "Tie!"
  │   ├─ Animation: Confetti + hearts rain
  │   └─ Sound: Victory chime
  │
  ├─→ Result Screen
  │   ├─ Final Scores displayed
  │   ├─ [Play Again] Button
  │   └─ [Back to Home] Button
  │
END

CLICK INTERACTION:
User clicks card #1
    ↓
Card flips (3D rotation 500ms, plays "click" sound)
    ↓
Emoji revealed
    ↓
User clicks card #2
    ↓
Card flips (3D rotation 500ms, plays "click" sound)
    ↓
Emoji revealed
    ↓
Compare emojis
    ├─ MATCH: Both stay flipped, score +1, "win" sound
    └─ NO MATCH: Wait 1s, flip back, "pop" sound, turn switches

3. CUPID SHOT 🏹 - GAME FLOW
═══════════════════════════════════════════════════════════════════════════════════

START
  │
  ├─→ Clear Canvas, Score = 0
  │   ├─ Display: "Cupid Shot - Click Hearts!"
  │   └─ Display Score: 0
  │
  ├─→ Fall Loop (Repeat until miss)
  │   │
  │   ├─→ Heart appears at random x position
  │   │   └─ Animates falling from top to bottom (1-2 seconds)
  │   │
  │   ├─→ While heart falling
  │   │   ├─ User can click the falling heart
  │   │   │
  │   │   ├─ If clicked:
  │   │   │  ├─ Heart disappears (pop animation + particles)
  │   │   │  ├─ Score +10 points
  │   │   │  ├─ Number "+10" floats up and fades
  │   │   │  ├─ Play "win" sound
  │   │   │  └─ Generate next heart
  │   │   │
  │   │   └─ If heart reaches bottom (missed):
  │   │      ├─ Game Over!
  │   │      ├─ Play "end" sound
  │   │      └─ Show Result
  │   │
  │   └─ Continue until miss
  │
  ├─→ Game Over Screen
  │   ├─ Display: "Game Over!"
  │   ├─ Display: Final Score: X points
  │   ├─ Animation: Confetti + celebration
  │   ├─ [Play Again] Button
  │   └─ [Back to Home] Button
  │
END

CLICK INTERACTION:
Heart appears on screen
    ↓
User clicks heart (cursor changes to crosshair)
    ↓
Heart exists AND is on screen?
    ├─ YES → Heart pops + score increases
    └─ NO → Miss (heart reached bottom)
    ↓
Continue until miss detected

5. DO YOU LOVE DEV? 💕 - GAME FLOW

START

  ├─→ Load Question Pool
  │   └─ Questions about loving Dev (20+ variations)
  │

  │   ├─ Display: "Do you love Dev?"
  │   ├─ Display: "Q1: Is Dev kind?" (or similar)
  │   ├─ Display: [YES] [NO] buttons
  │   └─ Question counter: 1/X
  │
  ├─→ Loop through all questions
  │   │
  │   ├─→ User clicks YES or NO

  │   ├─ Count YES answers

  │   │   └─ 90-100%: "You're 💯% in love!"
  │   │   └─ 70-89%: "Dev's the one! 💖"
  │   │   └─ 50-69%: "Growing love! 💕"
  │   │   └─ Below 50%: "Hmm... really? 😊"
  │   └─ Result color changes based on percentage
  │
  ├─→ Result Screen
  │   ├─ Display large percentage
  │   ├─ Display custom message
  │   ├─ Animation: Number counter animates up
  │   ├─ Confetti if very high score
  │   ├─ [Play Again] Button
  │   └─ [Back to Home] Button
  │
END

CLICK INTERACTION:
Question appears on screen
    ↓
User clicks [YES] or [NO]
    ↓
Current answer stored
    ↓
Question fades, next question slides in
    ↓
Repeat until all questions answered
    ↓
Calculate final percentage and display

SOUND EFFECTS TIMELINE
═══════════════════════════════════════════════════════════════════════════════════

Game Start:    "start" sound (ascending tone, 200ms)
Game Click:    "click" sound (600Hz, 100ms) - generic
Game Match:    "win" sound (800Hz, 300ms) - on successful match
Game Miss:     "pop" sound (500→100Hz, 150ms) - frequency sweep
Game End:      "end" sound (800→400Hz, 300ms) - descending tone

Each game triggers appropriate sounds at key moments.
